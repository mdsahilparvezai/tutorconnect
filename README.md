# TutorConnect

1. Project Setup — Next.js 14 + TypeScript + Tailwind
2. Auth — Supabase Phone OTP + Email
3. Onboarding — Tutor (4-step) & Student (3-step) wizards
4. Search & Discovery — Filters, cards, list/map toggle
5. Tutor Profile — Tabs, calendar, booking sidebar, reviews
6. Chat & Booking — Demo request, confirmation
7. AI Matching — Score + reasoning
8. Compare — Side-by-side tutors
9. Referrals — Code, stats, history
10. Batches — Browse / Create groups
11. Dashboards — Student, Tutor, Admin
12. Trust & Safety — Reports, verifications
